Python para principiantes

Notas de estudio con los fundamentos del lenguaje: sintaxis, tipos, operadores, control de flujo, funciones y clases.

01Comentarios

  • Un comentario es texto que el intérprete ignora; sirve para dejar notas dentro del código.
  • Con una # se comenta una sola línea.
  • Con comillas triples se puede comentar un bloque de varias líneas.
# comentario de una línea

"""
comentario
de varias líneas
"""

02Variables y constantes

  • Una variable guarda un valor bajo un nombre; en Python no se declara su tipo.
  • No existen constantes reales: por convención se escriben en mayúsculas para indicar que no deberían modificarse.
ciudad = "Madrid"
ciudad = 42        # el mismo nombre puede cambiar de tipo

VELOCIDAD_LUZ = 299792

03Tipos de datos

  • int números enteros · float decimales · bool verdadero/falso · str texto.
edad = 30
altura = 1.78
activo = False
nombre = "Ana"

04Mostrar mensajes

  • print() escribe en pantalla.
  • Con f"" se pueden insertar variables directamente dentro del texto.
print("Hola mundo")

dia = "lunes"
print(f"Hoy es {dia}")

05Operadores

Numéricos

  • + - * / // % ** suma, resta, multiplicación, división, división entera, resto y potencia.
7 // 2   # 3  (división sin decimales)
7 % 2    # 1  (resto)
2 ** 5   # 32 (potencia)

Comparación

  • == != > < >= <= comparan dos valores y devuelven True o False.

Lógicos

  • and exige que ambas condiciones se cumplan, or exige al menos una, not invierte el resultado.

Asignación

  • += -= *= /= //= **= %= operan sobre la variable y guardan el resultado en ella misma.

Identidad

  • is / is not comprueban si dos variables apuntan al mismo objeto en memoria (distinto de comparar su valor).

Pertenencia

  • in / not in comprueban si un elemento está dentro de una secuencia.

Bits

  • & | ^ ~ >> << operan sobre la representación binaria de los números.

06Arrays y listas

  • Una list guarda varios valores en una sola variable, entre corchetes.
  • .append() agrega un elemento al final.
frutas = ["manzana", "pera"]
frutas.append("uva")
print(frutas)   # ['manzana', 'pera', 'uva']

07Funciones

  • def agrupa instrucciones reutilizables; return devuelve un resultado.
  • No existen modificadores de acceso, pero un guion bajo inicial (_nombre) sugiere uso interno y un doble guion bajo (__nombre) dificulta el acceso desde fuera.
def area_circulo(radio):
    return 3.1416 * radio ** 2

print(area_circulo(4))

08Cadenas de texto

  • str almacena texto y admite métodos y concatenación con +.
saludo = "hola"
print(saludo.upper())     # HOLA
print(saludo + " mundo")

09Estructuras de control

Condicionales

  • if / elif / else ejecutan un bloque según se cumpla o no una condición.
nota = 6
if nota >= 5:
    print("Aprobado")
else:
    print("Suspenso")

Bucles

  • for recorre un número fijo de iteraciones; while repite mientras la condición sea verdadera.
for i in range(5):
    print(i)

restantes = 3
while restantes > 0:
    print(restantes)
    restantes -= 1

10Manejo de excepciones

  • try intenta ejecutar el código; except captura el error; finally se ejecuta siempre.
try:
    resultado = 10 / 0
except:
    print("Ha ocurrido un error")
finally:
    print("Fin del bloque")

11Clases

  • class define una plantilla para crear objetos; __init__() inicializa sus atributos y self los referencia.
  • Por convención, un guion bajo indica un atributo "protegido" y doble guion bajo uno "privado".
  • class Hija(Padre): crea herencia; super() reutiliza el constructor de la clase padre.
class Animal:
    def __init__(self, nombre):
        self.nombre = nombre

    def hablar(self):
        return f"{self.nombre} hace un sonido"

class Perro(Animal):
    def hablar(self):
        return f"{self.nombre} ladra"

print(Perro("Rex").hablar())

12Módulos

  • import permite reutilizar funciones de la biblioteca estándar o de otros archivos.
import math
print(math.sqrt(81))

07Funciones (métodos)

  • Un method es una función definida dentro de una clase; puede recibir parámetros y devolver un valor con return.

}

System.out.println(Geometria.areaCirculo(4));

11Clases

  • class define una plantilla para crear objetos; el constructor inicializa el estado y this referencia al objeto actual.
  • public, private y protected controlan quién puede acceder a cada miembro; final impide heredar o sobrescribir; abstract obliga a implementar en una subclase.
  • extends crea herencia; super() llama al constructor padre; @Override marca un método que sobrescribe al de la clase padre.
class Animal {
    protected String nombre;
    public Animal(String nombre) { this.nombre = nombre; }
    public String hablar() { return nombre + " hace un sonido"; }
}

class Perro extends Animal {
    public Perro(String nombre) { super(nombre); }
    @Override
    public String hablar() { return nombre + " ladra"; }
}

System.out.println(new Perro("Rex").hablar());
